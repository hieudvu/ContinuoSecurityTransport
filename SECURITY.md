# Security Policy

Report vulnerabilities privately to hvu@usecontinuo.app. Do not open a public
GitHub issue for an undisclosed vulnerability.

- Initial acknowledgement target: 3 business days
- Triage/status target: 7 business days
- Coordinated disclosure: agree timing before publication
- Supported version: the latest mirror snapshot and current signed Continuo release

Include a concise impact description, affected version or snapshot, reproduction
steps, and any proof material that can be shared safely. Avoid including secrets,
personal data, or unrelated user content. These response times are targets, not
guarantees.

The policy covers reports about this package and its behavior in the supported
Continuo release. Proprietary product surfaces outside the package may still be
relevant to an impact assessment; identify them in the private report when
known.
