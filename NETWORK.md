# Network Behavior

Continuo sends no telemetry and no keyboard, mouse, clipboard, or
transferred-file content to an Internet service. Peer content stays on the
authenticated local peer connection. Updates, licensing, downloads, payments,
and user-opened website links are separate documented Internet traffic.

## No telemetry

The security transport package does not add analytics or telemetry reporting.
Its peer-transport responsibility is local authenticated communication. The
top-level statement above distinguishes peer content from separate product
features that may contact Internet services.

Network behavior outside this package belongs to the proprietary application
and its separately documented update, licensing, download, payment, and
user-directed website flows.
